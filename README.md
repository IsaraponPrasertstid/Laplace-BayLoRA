Personalising LLMs with just a few labels using Bayesian DPO: This is basically to adapt the method from https://arxiv.org/pdf/1911.10183 to LLMs. Instead of building a large dataset for RLHF, which is expensive, we want to select just a handful of candidate responses that the user must compare and label. The method chooses these pairs of candidates. The method (Bayesian optimisation) can be adapted to summarisation with LLMs by using Bayesian LoRA instead of a Gaussian process.
